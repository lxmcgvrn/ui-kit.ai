## Usage

```tsx
import { FieldGroup } from '@ui-kit.ai/components'
```

`FieldGroup` draws the border and background that a field appears to have, and tracks hover, focus,
disabled and invalid state for everything inside it. Its children are therefore rendered
borderless — pass `isBorderless` to the `Input`, `TextArea` or `SelectButton` it wraps.
