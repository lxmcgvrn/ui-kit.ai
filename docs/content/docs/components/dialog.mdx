## Usage

```tsx
import {
    Dialog,
    DialogCloseButton,
    DialogContent,
    DialogFooter,
    DialogHeader,
    DialogModal,
    DialogModalOverlay,
    DialogTitle,
    DialogTrigger,
} from '@ui-kit.ai/components'
```

`Dialog` lays out three regions: a `DialogHeader` pinned to the top, a scrollable `DialogContent`,
and a `DialogFooter` pinned to the bottom. A button with `slot='close'` — or the built-in
`DialogCloseButton` — dismisses the dialog.

<Callout type='warn'>
    A dialog without a `DialogTitle` needs an `aria-label` or `aria-labelledby` prop instead, so it
    is identified to assistive technology.
</Callout>

## Modal

Wrap the dialog in `DialogModalOverlay` and `DialogModal`, and put both alongside a trigger element
inside `DialogTrigger`, to open the dialog as a modal. `Dialog` accepts a render function that
receives `close`, so footer actions can dismiss the dialog once they are done.

## Width

The `width` prop sets the dialog's width at the `md` breakpoint and above. Below it, the dialog is
full-screen regardless of this prop.
