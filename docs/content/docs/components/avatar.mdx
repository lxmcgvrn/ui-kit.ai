## Usage

```tsx
import { Avatar } from '@ui-kit.ai/components'
```

Pass either a `name`, an `src`, or both. With only a `name`, the avatar renders the initials
derived from it.

## Image

The `src` prop accepts a remote URL or a data URL. The image is preloaded, and the initials remain
visible until it has loaded.

<ComponentPreview name='avatar/with-image'>
    <AvatarWithImage />
</ComponentPreview>

## Shape

The `variant` prop controls the shape of the avatar. It defaults to `circle`.

The `isLoading` prop replaces the avatar's content with a spinner.

</ComponentPreview>

## Initials

A name containing a space is reduced to the first letter of its first two words. A single word is
reduced to its first letter.

### Single name

    <AvatarSingleName />
</ComponentPreview>

### No name

With neither a `name` nor an `src`, the avatar renders as an empty placeholder.
