## Usage

```tsx
import { DialogTrigger, Popover, PopoverDialog } from '@ui-kit.ai/components'
```

Wrap the trigger element and the `Popover` in a `DialogTrigger`. Put the popover's content in a
`PopoverDialog` so it is announced as a dialog, and use `showArrow` to point the overlay at its
trigger.

## Placement

react-aria supports a pretty comprehensive range of placement options, some of which are shown here.
It is important to note that the Popover may flip when it detects a collision with a parent or
window edge.
