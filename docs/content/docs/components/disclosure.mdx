## Usage

```tsx
import { Disclosure, DisclosureButton, DisclosurePanel } from '@ui-kit.ai/components'
```

`DisclosureButton` toggles the panel, and carries a chevron that rotates with the open state. Use
`defaultExpanded` to start open, or `isExpanded` with `onExpandedChange` to control it.
