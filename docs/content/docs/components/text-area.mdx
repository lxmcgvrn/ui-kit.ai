## Usage

```tsx
import { TextArea } from '@ui-kit.ai/components'
```

`TextArea` is a primitive: it is normally rendered inside a field component such as `TextField`,
which owns the label, description, validation state and value.

## Disabled

Set `aria-disabled` to "gray out" the text area.

<ComponentPreview name='text-area/disabled'>
    <TextAreaDisabled />
</ComponentPreview>

## Invalid

Set `aria-invalid` to apply the error styling.

<ComponentPreview name='text-area/invalid'>
    <TextAreaInvalid />
</ComponentPreview>

## Borderless

The `isBorderless` prop drops the border and background, for use inside an already-bordered
container such as a `FieldGroup`.
