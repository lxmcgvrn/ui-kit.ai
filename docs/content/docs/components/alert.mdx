## Usage

```tsx
import { Alert } from '@ui-kit.ai/components'
```

`text` is the only required prop. The `icon` prop overrides the default info icon, and defaults to
an `InfoIcon` when omitted.

## Actions

The `actions` prop accepts up to two react nodes — typically buttons — rendered below the message.
