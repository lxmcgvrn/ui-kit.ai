## Usage

```tsx
import {
    TextField,
    TextFieldClearButton,
    TextFieldCopyButton,
    TextFieldVisibilityButton,
} from '@ui-kit.ai/components'
```

`TextField` is composed from parts. A `FieldGroup` draws the border around the `Input` and any
trailing buttons: `TextFieldClearButton` empties the value, `TextFieldCopyButton` copies it to the
clipboard, and `TextFieldVisibilityButton` toggles between masked and plain text. Wrap the group in
a `Label` and `Description` to name and explain the field.

## Disabled

The `isDisabled` prop will "gray out" the field, and prevent focus and interaction.

<ComponentPreview name='text-field/disabled'>
    <TextFieldDisabled />
</ComponentPreview>

## Invalid

The `isInvalid` prop applies the error styling to the field and its decorations.

<ComponentPreview name='text-field/invalid'>
    <TextFieldInvalid />
</ComponentPreview>

## Read only

The `isReadOnly` prop keeps the field focusable and its value selectable, but prevents edits.
