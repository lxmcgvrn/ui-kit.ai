## Usage

```tsx
import { Tooltip, TooltipInfoButton, TooltipTrigger } from '@ui-kit.ai/components'
```

Wrap the trigger element and the `Tooltip` in a `TooltipTrigger`. `TooltipInfoButton` is a
ready-made info icon button for the common "explain this label" case.

## Trigger

The Tooltip can be composed with a number of different components, like `Button`, `Link`, `Tab` and
more. The element that triggers the tooltip must be able to receive focus.
