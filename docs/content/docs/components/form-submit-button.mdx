## Usage

```tsx
import { Form, FormSubmitButton } from '@ui-kit.ai/components'
```

`FormSubmitButton` accepts every `Button` prop, and reads `react-hook-form`'s state to manage two
of them itself: it stays disabled until the form is dirty, and shows a pending state while the
form is submitting or validating. Type in the field above to see the button become enabled.
