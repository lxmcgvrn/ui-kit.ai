## Usage

```tsx
import { SearchField, SearchFieldClearButton } from '@ui-kit.ai/components'
```

`SearchField` is composed from parts: a `FieldGroup` draws the border, an `Input` takes the query,
and `SearchFieldClearButton` empties it. The field also clears on `Escape` and submits on `Enter`.

## Disabled

The `isDisabled` prop will "gray out" the field, and prevent focus and interaction.

<ComponentPreview name='search-field/disabled'>
    <SearchFieldDisabled />
</ComponentPreview>

## Read only

The `isReadOnly` prop keeps the field focusable and its value selectable, but prevents edits.

<ComponentPreview name='search-field/read-only'>
    <SearchFieldReadOnly />
</ComponentPreview>

## With default value

Use `defaultValue` to render the field with an initial query in the uncontrolled case, or `value`
together with `onChange` to control it.

<ComponentPreview name='search-field/default-value'>
    <SearchFieldDefaultValue />
</ComponentPreview>

The field fills its container by default. Pass a `className` to constrain it.
