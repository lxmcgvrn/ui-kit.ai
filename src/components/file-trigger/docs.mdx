## Usage

```tsx
import { Button, FileTrigger } from '@ui-kit.ai/components'
```

Wrap any pressable element — usually a `Button` — and pressing it opens the file picker. `onSelect`
receives a `FileList`. The trigger renders no markup of its own beyond a hidden `<input>`, so the
child keeps its own styling.

## Accepted types

`acceptedFileTypes` filters the picker by MIME type, and `allowsMultiple` lets more than one file
through.

</ComponentPreview>

## Directories

`acceptDirectory` swaps the picker for a directory picker. `onSelect` still receives files — every
file inside the chosen folder.
