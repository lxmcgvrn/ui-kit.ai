## Usage

```tsx
import { ProgressBar } from '@ui-kit.ai/components'
```

`value` runs from `minValue` to `maxValue`, which default to 0 and 100. Pass `label` and the bar
renders a `Label` above the track with the formatted value opposite it.

Use `ProgressBar` for work that finishes — an upload, an import. For a measurement that simply
holds a value, such as disk usage, use `Meter`.

## Indeterminate

Set `isIndeterminate` when the work has started but its size is unknown. The fill gives up its
width and sweeps the track instead.

## Value label

The value is formatted as a percentage by default. Pass `formatOptions` to change that, or
`valueLabel` to write it yourself.
