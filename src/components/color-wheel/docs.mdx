## Usage

```tsx
import { ColorWheel } from '@ui-kit.ai/components'
```

The wheel edits the hue of the color passed as `defaultValue` or `value`. The track and the thumb
are rendered for you, so `ColorWheel` takes no children.

## Size

`outerRadius` and `innerRadius` set the ring's geometry in pixels — the wheel measures
`outerRadius * 2` on each side. They default to `96` and `72`.

## With a color area

The ring leaves room for a `ColorArea` at its centre, giving hue, saturation and brightness in one
control.

The `isDisabled` prop fades the wheel and prevents focus and interaction.
