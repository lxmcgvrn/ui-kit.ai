## Usage

```tsx
import { CalendarGrid, CalendarHeader, RangeCalendar } from '@ui-kit.ai/components'
```

`RangeCalendar` reuses `CalendarHeader` and `CalendarGrid` from `Calendar`, and renders both by
default. The two ends of the range take the primary color and keep the cell's rounded corners; the
days between them are tinted and square, so the range reads as one block.

## Multiple months

Pass `visibleDuration` to page more than one month at a time, then compose one `CalendarGrid` per
month with an `offset`.
