## Usage

```tsx
import {
    ComboBox,
    ComboBoxButton,
    ComboBoxClearButton,
    ComboBoxFieldGroup,
    ComboBoxInput,
} from '@ui-kit.ai/components'
```

`ComboBox` is composed from parts. `ComboBoxFieldGroup` wraps the trigger row and measures it so
the popover matches its width, `ComboBoxInput` filters the options as the user types,
`ComboBoxClearButton` appears once an option is selected, and `ComboBoxButton` toggles the popover.

Options are passed as data through the `items` prop rather than as children.

The `isDisabled` prop will "gray out" the combo box, and prevent focus and interaction.

## Borderless

Pass `isBorderless` to `ComboBoxFieldGroup` to drop the border and background, for use inside an
already-bordered container.
