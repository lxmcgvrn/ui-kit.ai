## Usage

```tsx
import { Separator } from '@ui-kit.ai/components'
```

`Separator` renders an `hr` wearing `border-default`. It carries no margin of its own — space it
with a `className` to suit the layout it divides.

## Vertical orientation

Set `orientation='vertical'` for a rule between controls in a row, such as inside a `Toolbar`. It
takes its height from the flex row it sits in, so it needs a flex parent.
