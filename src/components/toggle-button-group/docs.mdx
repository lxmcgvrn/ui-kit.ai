## Usage

```tsx
import { ToggleButton, ToggleButtonGroup } from '@ui-kit.ai/components'
```

Give every `ToggleButton` an `id` — that is the key the group reports through `selectedKeys` and
`onSelectionChange`. Arrow keys move between the buttons.

<Callout type='warn'>
    Set an `aria-label` on the group to give the set of toggles an accessible name.
</Callout>

Set `variant` once on the group and every button inside it picks it up, the way `Tabs` passes its
variant to each `Tab`. A button can still set its own `variant` to opt out.

## Multiple selection

Set `selectionMode='multiple'` to let more than one option be on at a time. The default is
`single`; add `disallowEmptySelection` to keep one option always chosen.

## Detached

The buttons are attached by default. Set `isAttached={false}` to space them out instead — useful
for a row of filter chips, where the options are not alternatives to each other.

## Vertical orientation

Set `orientation='vertical'` to stack the run. The shared edges and rounded corners follow.
