## Usage

```tsx
import { Label } from '@ui-kit.ai/components'
```

Render a `Label` inside a field component — react-aria handles the `id` and `for` attributes that
tie it to the input.

## Controls with no label slot

A few controls — `ToggleButtonGroup` among them — render no label slot for a `Label` to fill. Hand
the pair an `id` through react-aria's `LabelContext`, then point the control at it:

```tsx
function SettingRow() {
    const id = useId()

    return (
        <LabelContext value={{ id }}>
            <Label>Radius</Label>
            <ToggleButtonGroup aria-labelledby={id}>{stops}</ToggleButtonGroup>
        </LabelContext>
    )
}
```
