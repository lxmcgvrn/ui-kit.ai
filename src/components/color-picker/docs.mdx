## Usage

```tsx
import { ColorPicker } from '@ui-kit.ai/components'
```

`ColorPicker` is the whole control: a trigger showing the current color as a `ColorSwatch` beside
its hex value, and a popover holding a `ColorArea`, hue and alpha `ColorSlider`s, and a hex
`ColorField`. It keeps every one of them on the same color, so none of them needs its own `value`.

## Label

The trigger shows the hex value by default. Pass `label` to name the color instead.

</ComponentPreview>

## Custom content

`children` replaces the contents of the popover. Any color component inside still reads and writes
the picker's color.

    <ColorPickerCustomContent />
</ComponentPreview>

## Controlled

Pass `value` and `onChange` to drive the color from your own state. `onChange` receives a react-aria
`Color`, which formats to any supported color string.
