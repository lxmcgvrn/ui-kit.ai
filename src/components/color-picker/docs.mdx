## Usage

```tsx
import { ColorPicker } from '@ui-kit.ai/components'
```

`ColorPicker` is a root, not a control. It draws nothing of its own: put any `ColorArea`,
`ColorSlider`, `ColorWheel`, `ColorField`, `ColorSwatch` or `ColorSwatchPicker` inside it and they
all read and write the same color, so none of them needs its own `value`. Name it by composing a
`Label`, like any other field.

## In a popover

There is no trigger built in. Compose one: a `DialogTrigger` with a `Button` and a `Popover` inside
the picker puts the controls behind a swatch. Pass a function as `children` to read the current
color.

## Controlled

Pass `value` and `onChange` to drive the color from your own state. `onChange` receives a react-aria
`Color`, which formats to any supported color string.
