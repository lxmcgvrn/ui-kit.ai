## Usage

```tsx
import {
    FieldGroup,
    Input,
    NumberField,
    NumberFieldDecrementButton,
    NumberFieldIncrementButton,
} from '@ui-kit.ai/components'
```

`NumberField` is composed from parts. A `FieldGroup` draws the border around the `Input` and the
steppers: `NumberFieldDecrementButton` steps the value down and `NumberFieldIncrementButton` steps
it up. Both are wired up for you — `NumberField` sets their press handlers and disables them at the
ends of the range. Use `minValue`, `maxValue`, and `step` to constrain the value.

## Format options

`formatOptions` takes any `Intl.NumberFormat` options, so the field can render currencies,
percentages, or units, and parse what the user types back in the same format.
