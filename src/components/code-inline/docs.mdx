## Usage

```tsx
import { CodeInline } from '@ui-kit.ai/components'
```

Use `CodeInline` for a short snippet inside a line of prose. Pass the snippet as children and the
language as `language`.

## Languages

Any language supported by [Prism](https://prismjs.com) can be passed to `language`.
