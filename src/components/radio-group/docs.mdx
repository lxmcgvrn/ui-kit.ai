## Usage

```tsx
import { Description, Label, Radio, RadioGroup } from '@ui-kit.ai/components'
```

Compose a `RadioGroup` from a `Label`, one `Radio` per option, and an optional `Description`. Each
`Radio` needs a `value`, which is what the group reports as selected. A `Radio` renders its own
`label` and `description`, and only works inside a group.

## Text position

The `textPosition` prop on a `Radio` controls which side of the circle its text sits on.

## Invalid

The `isInvalid` prop marks the whole group as failing validation.

## Disabled

The `isDisabled` prop grays out every radio in the group and prevents focus and interaction.
