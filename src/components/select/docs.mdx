## Usage

```tsx
import { Select, SelectButton } from '@ui-kit.ai/components'
```

Options are passed as data through the `items` prop rather than as children. `SelectButton`
triggers the popover and renders the selected option's text value — it is the default child, so it
only needs to be written out when the select is composed with a `Label` or `Description`.

## Invalid

The `isInvalid` prop applies the error styling to the field.

## Disabled

The `isDisabled` prop will "gray out" the select, and prevent focus and interaction.

<ComponentPreview name='select/disabled'>
    <SelectDisabled />
</ComponentPreview>

## Borderless

Pass `isBorderless` to `SelectButton` to drop the border and background, for use inside an
already-bordered container.

    <SelectBorderless />
</ComponentPreview>

## Disabled keys

The `disabledKeys` prop takes the `id` of each option that should be non-selectable.
