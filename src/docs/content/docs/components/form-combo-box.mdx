## Usage

```tsx
import {
    ComboBoxButton,
    ComboBoxClearButton,
    ComboBoxFieldGroup,
    ComboBoxInput,
    Description,
    Form,
    FormComboBox,
    Label,
} from '@ui-kit.ai/components'
```

`FormComboBox` registers itself with the surrounding `Form` under the `name` you give it, and
renders a `FieldError` for you so validation messages from `react-hook-form` appear without any
extra wiring. Pass the options through `items`, and compose the field body from a `Label`, a
`ComboBoxFieldGroup` containing a `ComboBoxInput`, `ComboBoxClearButton` and `ComboBoxButton`,
and an optional `Description`. The `name` prop is required — the component throws without it.

## Sections

`items` accepts section entries — objects with their own nested `items` array — to group the
options under headings.

<ComponentPreview name='form-combo-box/with-sections'>
    <FormComboBoxWithSections />

## Invalid

The `isInvalid` prop marks the field as failing validation. The field is also marked invalid
automatically whenever the form reports an error for it.

<ComponentPreview name='form-combo-box/is-invalid'>
    <FormComboBoxIsInvalid />
</ComponentPreview>

## Disabled

The `isDisabled` prop grays out the field and prevents focus and interaction.

<ComponentPreview name='form-combo-box/is-disabled'>
    <FormComboBoxIsDisabled />
</ComponentPreview>

## With disabled keys

Pass `disabledKeys` an array of option ids to leave the field interactive while making individual
options unselectable.

</ComponentPreview>
