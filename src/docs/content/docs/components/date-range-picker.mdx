## Usage

```tsx
import {
    DateRangePicker,
    DateRangePickerButton,
    DateRangePickerFieldGroup,
    DateRangePickerInput,
} from '@ui-kit.ai/components'
```

`DateRangePickerFieldGroup` draws the field border around a `DateRangePickerInput` and a
`DateRangePickerButton`, and renders both by default. `DateRangePickerInput` pairs the start and end
`DateInput`s with a dash between them. `DateRangePicker` supplies the popover and the
`RangeCalendar` inside it.

The value is an object with `start` and `end` dates rather than a single date.

## Granularity

The `granularity` prop adds time segments to both fields. Use `hour`, `minute`, or `second`.

The `isDisabled` prop will "gray out" the picker, and prevent focus and interaction.
