## Usage

```tsx
import { DateRangePicker, DateRangePickerButton, DateRangePickerInput, FieldGroup } from '@ui-kit.ai/components'
```

`DateRangePicker` is composed from parts: a `FieldGroup` draws the field border around a
`DateRangePickerInput` and a `DateRangePickerButton`, and that composition is the default child.
`DateRangePickerInput` pairs the start and end `DateInput`s with a dash between them.
`DateRangePicker` supplies the popover and the `RangeCalendar` inside it.

The value is an object with `start` and `end` dates rather than a single date.

## Clearable

Compose in a `FieldButtonClear` to let the user drop the range — `DateRangePicker` wires up the
press, and hides the button while the fields are empty.

## Granularity

The `granularity` prop adds time segments to both fields. Use `hour`, `minute`, or `second`.
