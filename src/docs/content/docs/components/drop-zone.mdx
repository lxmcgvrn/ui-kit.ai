## Usage

```tsx
import { DropZone, DropZoneLabel } from '@ui-kit.ai/components'
```

`onDrop` receives the dropped items. Put a `DropZoneLabel` inside — it is both the visible label and
the zone's accessible name. The border turns solid and the surface tints while a valid drag is over
the zone.

## With a file trigger

Dragging is not the only way in: pair the zone with a `FileTrigger` so a click opens the file picker
too.
