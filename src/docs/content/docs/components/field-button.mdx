## Usage

```tsx
import { FieldButton } from '@ui-kit.ai/components'
```

`FieldButton` is designed to be used inside field components to provide additional functionality
like clearing, copying, or toggling visibility. The ready-made variants — `TextFieldClearButton`,
`TextFieldCopyButton`, `TextFieldVisibilityButton` and `SearchFieldClearButton` — are all built on
it.

<Callout type='warn'>Set an `aria-label` to give the button an accessible name, since it only ever renders an icon.</Callout>

## Disabled

The `isDisabled` prop will "gray out" the button and prevent interaction.
