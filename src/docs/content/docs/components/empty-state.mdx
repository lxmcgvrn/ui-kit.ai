## Usage

```tsx
import { EmptyState } from '@ui-kit.ai/components'
```

`title` is the only required prop. `body` adds supporting copy, `icon` overrides the default info
icon, and `actions` accepts up to two react nodes — typically buttons — laid out below the body.
