## Usage

```tsx
import { Switch } from '@ui-kit.ai/components'
```

The `label` prop renders the switch's visible label, and `description` renders supporting text
beneath it. Reach for a `Switch` when the change applies straight away, and a `Checkbox` when the
value is submitted with a form.

## Text position

The `textPosition` prop controls which side of the track the label and description sit on.

## Disabled

The `isDisabled` prop grays out the switch and prevents focus and interaction.

<ComponentPreview name='switch/is-disabled'>

</ComponentPreview>

## Invalid

The `isInvalid` prop applies the error styling. A switch has no validation state of its own, so
pass it from whatever is validating the value — `FormSwitch` does this for you.
