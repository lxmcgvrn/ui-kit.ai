## Usage

```tsx
import { Calendar, CalendarCell, CalendarGrid, CalendarHeader } from '@ui-kit.ai/components'
```

`Calendar` renders a `CalendarHeader` and a `CalendarGrid` by default, so it works with no children
at all. `CalendarHeader` holds the month title and the previous and next buttons; `CalendarGrid`
renders the weekday names and a `CalendarCell` per day. Today is tinted, and the selected day takes
the primary color.

`CalendarGrid` and `CalendarHeader` are shared with `RangeCalendar`, and `CalendarCell` styles
itself for whichever of the two it is rendered in.

## Multiple months

Pass `visibleDuration` to page more than one month at a time, then compose one `CalendarGrid` per
month with an `offset`.

The `isDisabled` prop will "gray out" the calendar, and prevent focus and interaction.

The `isReadOnly` prop keeps the calendar focusable and navigable, but prevents selection.
