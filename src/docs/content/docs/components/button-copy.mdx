## Usage

```tsx
import { ButtonCopy } from '@ui-kit.ai/components'
```

An icon button: `aria-label` names what pressing copies. `getValue` builds the string to copy — it
runs on press, not on render, so it can read whatever is current at the moment of the click. On a
successful copy, the clipboard icon animates into a check for a moment before reverting, via
[AnimatedIconContainer](/docs/components/animated-icon-container).

## Computed value

`getValue` is only called when the button is pressed, so it can compute something fresh each time.
