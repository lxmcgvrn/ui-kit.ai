## Usage

```tsx
import { FieldError } from '@ui-kit.ai/components'
```

`FieldError` renders below the field it belongs to and is only shown while the field is invalid.
The form field components — `FormTextField`, `FormSelect`, `FormComboBox`, `FormCheckboxGroup` —
render one for you and wire it to the matching `react-hook-form` error, so it rarely needs to be
written out by hand.
