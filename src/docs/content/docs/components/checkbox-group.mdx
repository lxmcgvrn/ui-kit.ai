## Usage

```tsx
import { Checkbox, CheckboxGroup, Description, Label } from '@ui-kit.ai/components'
```

Compose a `CheckboxGroup` from a `Label`, one `Checkbox` per option, and an optional
`Description`. Each `Checkbox` needs a `value`, which is what the group reports as selected.

## Invalid

The `isInvalid` prop marks the whole group as failing validation.

<ComponentPreview name='checkbox-group/is-invalid'>
  <CheckboxGroupIsInvalid />
</ComponentPreview>

## Disabled

The `isDisabled` prop grays out every checkbox in the group and prevents focus and interaction.
