## Usage

```tsx
import { Chat, ChatMessage } from '@ui-kit.ai/components'
```

`Chat` is the container; each `ChatMessage` takes a `content` string, a stable `id`, and an
`origin` of `us` or `them`, which determines the alignment and styling of the bubble. `content` is
rendered with the [`Markdown`](/docs/components/markdown) component, so it supports the same
formatting.

Because `content` is a plain string, a streamed response can be rendered by updating it as tokens
arrive — the demo above replays a message one character at a time.
