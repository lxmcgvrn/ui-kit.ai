## Usage

```tsx
import { Cell, Column, Row, Table, TableBody, TableHeader } from '@ui-kit.ai/components'
```

A table is composed of a `TableHeader` containing `Column` elements, and a `TableBody` containing
`Row` elements made up of `Cell` elements. Mark the column that identifies each row with
`isRowHeader`, and use `alignment` on a `Column` and its matching `Cell` elements to right-align
numeric data.

<Callout type='warn'>
    Set an `aria-label` (or `aria-labelledby`) on the table to give it an accessible name.
</Callout>

The table does not paginate itself. Compose the controls you need underneath it — here a row
count, a set of page `Button` elements, and a `Select` for the page size.
