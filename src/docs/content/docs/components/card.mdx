## Usage

```tsx
import { Card, CardBody, CardDescription, CardFooter, CardHeader, CardTitle } from '@ui-kit.ai/components'
```

`Card` is a plain container. Compose it with `CardHeader`, `CardTitle`, `CardDescription`,
`CardBody` and `CardFooter` to get consistent spacing and typography.

## Card with form

A card composes with `Form` to group a set of fields, with the submit button in the footer.

<ComponentPreview name='card/with-form'>
  <CardWithForm />
</ComponentPreview>

## Custom className

The `className` prop is merged with the card's own classes, so layout utilities such as widths can
be applied directly.
