## Usage

```tsx
import { Description, Form, FormSelect, Label, SelectButton } from '@ui-kit.ai/components'
```

`FormSelect` registers itself with the surrounding `Form` under the `name` you give it, and
renders a `FieldError` for you so validation messages from `react-hook-form` appear without any
extra wiring. Pass the options through `items`, and compose the field body from a `Label`, a
`SelectButton`, and an optional `Description`. The `name` prop is required — the component throws
without it.

## Invalid

The `isInvalid` prop marks the field as failing validation. The field is also marked invalid
automatically whenever the form reports an error for it.

<ComponentPreview name='form-select/is-invalid'>
    <FormSelectIsInvalid />
</ComponentPreview>

## Disabled

The `isDisabled` prop grays out the field and prevents focus and interaction.

<ComponentPreview name='form-select/is-disabled'>

</ComponentPreview>

## Borderless

`Select` is the unconnected version of the same component, for use outside a `Form`. Its
`SelectButton` accepts an `isBorderless` prop for placing the control inside a `FieldGroup` that
already draws its own border.

<ComponentPreview name='form-select/is-borderless'>
    <FormSelectIsBorderless />
</ComponentPreview>

## Disabled keys

Pass `disabledKeys` an array of option ids to leave the field interactive while making individual
options unselectable.
