## Usage

```tsx
import { TagGroup, TagGroupItem, TagList } from '@ui-kit.ai/components'
```

`TagGroup` wraps a `TagList`, which holds one `TagGroupItem` per tag. Tags are passed as data
through the `items` prop, or written out as children.

<Callout>
  The item is called `TagGroupItem` rather than `Tag`, because `Tag` is already the presentational badge. Reach for `Tag` when the tag is
  only there to be read, and for `TagGroupItem` when the user can focus, select, or remove it. The two share an appearance.
</Callout>

`TagGroup` renders no label of its own. Put a `Label` inside it, or give it an `aria-label`.

## Selection

Set `selectionMode` to `single` or `multiple` on the `TagGroup`. Selected tags take on the solid
appearance, matching `Tag`'s `solid` variant.

## Removal

Pass `onRemove` to the `TagGroup` and each tag grows a remove button. `TagList` takes
`renderEmptyState` for the case where the last tag has gone.

## Intents

`intent` colors a tag semantically, exactly as it does on `Tag`, and `slotLeft` accepts a
decorative node such as an icon.
