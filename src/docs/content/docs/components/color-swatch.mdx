## Usage

```tsx
import { ColorSwatch } from '@ui-kit.ai/components'
```

The `color` prop accepts any CSS color string, or a react-aria `Color` object. The swatch is
`size-8` with a rounded border by default.

## Custom size

## Alpha

A translucent color sits on a checkerboard, so its alpha reads as alpha rather than as a lighter
shade of the surface behind it.
