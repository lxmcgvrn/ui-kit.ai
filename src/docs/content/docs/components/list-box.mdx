## Usage

```tsx
import { ListBox } from '@ui-kit.ai/components'
```

Options are passed as data through the `items` prop rather than as children. `ListBox` renders the
list only — it has no border or background of its own, so it is normally placed inside a container
such as a `Popover`. It also backs the option lists inside `Select` and `ComboBox`.

## Sections

Options can be grouped by nesting them under a section entry in `items`.
