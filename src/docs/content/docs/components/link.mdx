## Usage

```tsx
import { Link } from '@ui-kit.ai/components'
```

`Link` renders an anchor when given an `href`, and supports the same keyboard and pointer
interactions as a native link.

## With icon

Icons and other elements can be added as children to make a link more informative.

## Custom styling

The `className` prop applies custom classes on top of the link's own styles. It also accepts a
function of the render props, for styling based on interaction state.
