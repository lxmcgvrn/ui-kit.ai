## Usage

```tsx
import { Menu, MenuTrigger, Popover } from '@ui-kit.ai/components'
```

`MenuTrigger` takes two children: the element that opens the menu, and a `Popover` containing the
`Menu`. Options are passed as data through the `items` prop rather than as children.

## Sections

Options can be grouped by nesting them under a section entry in `items`.

  <MenuSections />
</ComponentPreview>

## Disabled keys

The `disabledKeys` prop takes the `id` of each option that should be non-selectable.
