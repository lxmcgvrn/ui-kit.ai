## Usage

```tsx
import { DateInput, DatePicker, DatePickerButton, FieldGroup } from '@ui-kit.ai/components'
```

`DatePicker` is composed from parts: a `FieldGroup` draws the field border around a `DateInput` and
a `DatePickerButton`, and that composition is the default child. `DatePicker` supplies the popover
and the `Calendar` inside it.

## Clearable

Compose in a `FieldButtonClear` to let the user drop the date — `DatePicker` wires up the press,
and hides the button while the field is empty.

## Granularity

The `granularity` prop adds time segments to the field. Use `hour`, `minute`, or `second`.

## Invalid

The `isInvalid` prop applies the error styling to the field.
