## Usage

```tsx
import { DatePicker, DatePickerButton, DatePickerFieldGroup } from '@ui-kit.ai/components'
```

`DatePickerFieldGroup` draws the field border around a `DateInput` and a `DatePickerButton`, and
renders both by default. `DatePicker` supplies the popover and the `Calendar` inside it, so the
field group is the only child that has to be written out.

## Granularity

The `granularity` prop adds time segments to the field. Use `hour`, `minute`, or `second`.

## Invalid

The `isInvalid` prop applies the error styling to the field.

## Disabled

The `isDisabled` prop will "gray out" the picker, and prevent focus and interaction.
