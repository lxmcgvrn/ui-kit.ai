## Usage

```tsx
import { Input } from '@ui-kit.ai/components'
```

`Input` is a primitive: it is normally rendered inside a field component such as `TextField`,
`SearchField` or `ComboBox`, which owns the label, description, validation state and value.

## With icon

The `icon` prop renders a decorative node inside the leading edge of the input, and adds the
padding needed to clear it.

</ComponentPreview>

## Borderless

The `isBorderless` prop drops the border and background, for use inside an already-bordered
container such as a `FieldGroup`.
