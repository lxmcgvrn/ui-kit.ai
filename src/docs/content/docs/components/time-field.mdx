## Usage

```tsx
import { DateInput, TimeField } from '@ui-kit.ai/components'
```

`TimeField` is a container: pass a `Label`, a `DateInput`, and a `Description` as children.
`DateInput` is shared with `DateField` — inside a `TimeField` it renders hour, minute, and day
period segments instead of date segments.

## Granularity

The `granularity` prop sets the smallest editable unit. Use `hour`, `minute`, or `second`.

## Hour cycle

The `hourCycle` prop overrides the locale default. Pass `12` or `24`.

## Disabled

The `isDisabled` prop will "gray out" the field, and prevent focus and interaction.
