## Usage

```tsx
import { ColorField, Input, Label } from '@ui-kit.ai/components'
```

`ColorField` is a container: pass a `Label` and an `Input` as children. Set the starting color with
`defaultValue`, or control it with `value` and `onChange`.

## Clear and copy

Wrap the `Input` in a `FieldGroup` and compose in `FieldButtonClear` and `FieldButtonCopy` —
`ColorField` wires up their presses. Clearing empties the field, and copying puts the current hex
on the clipboard.
