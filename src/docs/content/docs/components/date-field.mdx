## Usage

```tsx
import { DateField, DateInput, DateSegment } from '@ui-kit.ai/components'
```

`DateField` is a container: pass a `Label`, a `DateInput`, and a `Description` as children.
`DateInput` draws the field border and renders one `DateSegment` per part of the date — it is the
default child, so it only needs to be written out when the field is composed with other parts.

Values are `@internationalized/date` objects rather than strings. Set the starting date with
`defaultValue`, or control it with `value` and `onChange`.

## Clearable

Wrap the `DateInput` in a `FieldGroup` and compose in a `FieldButtonClear` — `DateField` wires up
the press, and hides the button while the field is empty.

## Granularity

The `granularity` prop adds time segments to the field. Use `hour`, `minute`, or `second`.

## Disabled

The `isDisabled` prop will "gray out" the field, and prevent focus and interaction.
