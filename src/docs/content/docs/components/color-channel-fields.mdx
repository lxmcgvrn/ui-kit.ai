## Usage

```tsx
import { ColorChannelFields } from '@ui-kit.ai/components'
```

`ColorChannelFields` takes only a `colorSpace` — `'rgb'`, `'hsl'`, or `'hsb'` — and renders that
space's channels as a row of `ColorField`s. Each field reads and writes the surrounding
`ColorPicker`, so drop it inside one and it works with no `value` or `onChange` of your own. Each
label shows the channel's initial and carries the full name for screen readers.
