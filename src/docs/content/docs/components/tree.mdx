## Usage

```tsx
import { Tree, TreeItem } from '@ui-kit.ai/components'
```

A `TreeItem` takes its row content as `title` and its nested rows as children. Rows with children
grow a chevron — the same rotating chevron as `Disclosure` — and indent one step per level. Use
`defaultExpandedKeys` to start some branches open, or `expandedKeys` with `onExpandedChange` to
control them.

<Callout type='warn'>
  Every `TreeItem` needs a `textValue` so typeahead and screen readers have something to work with, and an `id` unless it comes from
  `items`.
</Callout>

## Expand icon on the right

The `expandIconPosition` prop moves the chevron to the far side of each row, which suits
navigation trees. Rows without children give up their leading indent too.

## Multiple selection

With `selectionMode='multiple'` each row prepends a `Checkbox`, the same one the rest of the
library uses.

</ComponentPreview>

## Dynamic items

Pass nested data through `items`, and render each level's children with a `Collection`. The `title`
takes a react node, so a row can carry an icon.
