## Usage

```tsx
import { ColorArea } from '@ui-kit.ai/components'
```

The area edits two channels of the color passed as `defaultValue` or `value` — saturation and
brightness by default. The thumb is rendered for you, so `ColorArea` takes no children.

## Channels

`xChannel` and `yChannel` pick which channels the two axes edit. Which channels are available
depends on the `colorSpace`.

<ComponentPreview name='color-area/channels'>
  <ColorAreaChannels />
</ComponentPreview>

## Size

The area is `size-48` by default. Size it with the `className` prop.

<ComponentPreview name='color-area/with-sliders'>
  <ColorAreaWithSliders />
</ComponentPreview>

Pair it with a `ColorSlider` for the remaining channels, or drop both inside a `ColorPicker` to keep
them on one color without wiring either.

## Disabled

The `isDisabled` prop fades the area and prevents focus and interaction.
