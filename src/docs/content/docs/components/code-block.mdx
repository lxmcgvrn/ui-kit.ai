## Usage

```tsx
import { CodeBlock } from '@ui-kit.ai/components'
```

Pass the source as children and the language as `language`. Line numbers are shown by default —
set `showLineNumbers={false}` to hide them. A copy button is rendered in the top right corner.

## Languages

Any language supported by [Prism](https://prismjs.com) can be passed to `language`.
