## Usage

```tsx
import { Tab, TabList, TabPanel, Tabs } from '@ui-kit.ai/components'
```

`Tabs` wraps a single `TabList` and one `TabPanel` per tab. Each `Tab` is matched to its panel by
`id`, and can be clicked, tapped, or navigated to with the arrow keys.

<Callout type='warn'>
    Set an `aria-label` on the `TabList` to give the set of tabs an accessible name.
</Callout>

## Segmented

Set `variant='segmented'` for a segmented control: no rule under the row, and the selected tab
sits in a pill tinted like a selected list item. Set it once on `Tabs` — `TabList` and `Tab` pick
it up.

<ComponentPreview name='tabs/segmented'>
    <TabsSegmented />
</ComponentPreview>

## Vertical orientation

Set `orientation='vertical'` to stack the tabs down the side of the panel. Both variants support
it — segmented tabs become a column of full-width pills.
