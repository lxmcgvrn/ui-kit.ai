## Usage

```tsx
import { Form, FormSwitch } from '@ui-kit.ai/components'
```

`FormSwitch` takes the same props as a `Switch`, and additionally registers itself with the
surrounding `Form` under the `name` you give it. The form value is a `boolean`. The `name` prop is
required — the component throws without it.

Unlike the other form components, `FormSwitch` renders no `FieldError`: a switch has no children to
put one in, and no validation state of its own. It marks itself invalid when the form reports an
error for its field, so render the message yourself if you need one.

## Invalid

The `isInvalid` prop applies the error styling. The switch is also marked invalid automatically
whenever the form reports an error for its field.
