## Usage

```tsx
import { ColorSwatchPicker, ColorSwatchPickerItem } from '@ui-kit.ai/components'
```

Give each `ColorSwatchPickerItem` a `color`, and the picker a `defaultValue` or `value`. Each item
renders a `ColorSwatch` of its own color, so it needs no children. The selected item is ringed in
the accent color.

## Layout

`layout` sets both the visual direction and the arrow keys that move between swatches — `grid`
(the default) wraps horizontally, `stack` runs down a single column.

## Custom swatch

Pass a `ColorSwatch` as the item's children to restyle it. Leave off its `color` — the item
supplies it.

An item with `isDisabled` fades and cannot be selected.
