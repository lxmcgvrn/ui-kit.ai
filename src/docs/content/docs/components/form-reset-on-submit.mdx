## Usage

```tsx
import { Form, FormResetOnSubmit } from '@ui-kit.ai/components'
```

`FormResetOnSubmit` renders nothing. Drop it anywhere inside a `Form` and it will clear every
field once `onSubmit` resolves without throwing. Submit the form above to see the field empty
itself.

## Props

`FormResetOnSubmit` takes no props.
