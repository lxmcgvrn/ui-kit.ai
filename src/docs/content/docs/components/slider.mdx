## Usage

```tsx
import { Label, Slider, SliderOutput, SliderThumb, SliderTrack } from '@ui-kit.ai/components'
```

Compose a `Slider` from a `Label`, a `SliderOutput` for the current value, and a `SliderTrack`
holding one `SliderThumb` per value. The track draws its own rail and filled portion. Use
`minValue`, `maxValue`, and `step` to constrain the value, and `formatOptions` to change how
`SliderOutput` renders it.

## Range

Pass an array to `defaultValue` or `value` and render one `SliderThumb` per entry, each with its
`index`. The track fills the span between the thumbs.

## Vertical

The `orientation` prop turns the slider on its side. A vertical slider fills the height it is
given, so set one on the `Slider` itself.

  <SliderVertical />
</ComponentPreview>

## Disabled

The `isDisabled` prop grays out the slider and prevents focus and interaction.
