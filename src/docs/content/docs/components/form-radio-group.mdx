## Usage

```tsx
import { Description, Form, FormRadioGroup, Label, Radio } from '@ui-kit.ai/components'
```

`FormRadioGroup` takes the same children as a `RadioGroup`, and additionally registers itself with
the surrounding `Form` under the `name` you give it. It renders a `FieldError` for you, so
validation messages from `react-hook-form` appear without any extra wiring. The field's value is
the `value` of the selected `Radio`, or `null` while nothing is selected. The `name` prop is
required — the component throws without it.

## Disabled

The `isDisabled` prop grays out every radio in the group and prevents focus and interaction.

<ComponentPreview name='form-radio-group/disabled'>
    <FormRadioGroupDisabled />
</ComponentPreview>

## Invalid

The `isInvalid` prop marks the whole group as failing validation. The group is also marked invalid
automatically whenever the form reports an error for its field.
