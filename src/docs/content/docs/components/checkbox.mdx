## Usage

```tsx
import { Checkbox } from '@ui-kit.ai/components'
```

The `label` prop renders the checkbox's visible label, and `description` renders supporting text
beneath it. Use a `Checkbox` on its own to toggle a single value, or inside a `CheckboxGroup` to
select several values at once.

## Text position

The `textPosition` prop controls which side of the box the label and description sit on.
