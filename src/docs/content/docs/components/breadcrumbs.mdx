Breadcrumbs display a hierarchy of links to the current page. The last item is typically not a
link, and represents the current page.

<ComponentPreview name='breadcrumbs/default'>
  <BreadcrumbsDefault />
</ComponentPreview>

## Usage

```tsx
import { Breadcrumb, Breadcrumbs } from '@ui-kit.ai/components'
```

Each `Breadcrumb` with an `href` renders as a link, followed by a chevron separator. Omit the
`href` on the final item so it renders as plain text.

## Disabled

The `isDisabled` prop on `Breadcrumbs` prevents interaction with every link in the trail.

<ComponentPreview name='breadcrumbs/disabled'>
  <BreadcrumbsDisabled />
</ComponentPreview>

## Custom items

`Breadcrumb` accepts arbitrary children, so items can carry icons or other content.
