## Usage

```tsx
import { GridList, GridListItem } from '@ui-kit.ai/components'
```

A `GridList` holds `GridListItem` rows, passed as data through the `items` prop or written out as
children. Unlike `ListBox`, a row can contain its own focusable controls, which the user reaches
with the arrow keys.

<Callout type='warn'>
  Set an `aria-label` (or `aria-labelledby`) on the list to give it an accessible name, and a `textValue` on any row whose children are not
  plain text.
</Callout>

## Multiple selection

With `selectionMode='multiple'` each row prepends a `Checkbox`, the same one the rest of the
library uses.
