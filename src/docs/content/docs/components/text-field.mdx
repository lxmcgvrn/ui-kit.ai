## Usage

```tsx
import { FieldButtonClear, FieldButtonCopy, FieldButtonVisibility, TextField } from '@ui-kit.ai/components'
```

`TextField` is composed from parts. A `FieldGroup` draws the border around the `Input` and any
trailing buttons: `FieldButtonClear` empties the value, `FieldButtonCopy` copies it to the
clipboard, and `FieldButtonVisibility` toggles between masked and plain text. Wrap the group in
a `Label` and `Description` to name and explain the field.

## Disabled

The `isDisabled` prop will "gray out" the field, and prevent focus and interaction.
